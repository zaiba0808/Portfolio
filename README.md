# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built using **HTML5, CSS3, and Vanilla JavaScript**.

Designed for showcasing education, skills, projects, certifications, and contact information in a clean and professional format.

# 🚀 Part 7 : Professional Tips

## Profile Photo

✔ Plain background

✔ Good lighting

✔ Smile naturally

✔ Formal or smart casual attire

✔ High resolution

---

## About Section

Keep it concise.

Mention

- Degree
- Interests
- Career Goal
- Technologies

Avoid long paragraphs.

---

## Recruiter Friendly Tips

✔ Keep navigation simple

✔ Highlight best projects

✔ Include GitHub

✔ Include LinkedIn

✔ Downloadable Resume

✔ Mobile Friendly

---

## Basic SEO

Use

- Proper page title
- Meta description
- Semantic HTML
- Alt text for images

---

## Performance

Compress images.

Keep JavaScript lightweight.

Avoid unnecessary libraries.

Optimize image sizes.

---

## Accessibility

Use

- High color contrast
- Keyboard navigation
- Descriptive link text
- Alt text on images
- Proper heading order
